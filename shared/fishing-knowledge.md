# 낚시 장르별 세팅 지식베이스

---

## 광어 캐스팅 (연안/방파제)

### 릴
- 2500~3000번 스피닝릴 적합
- 하이기어(HG) 이상 권장 — 빠른 라인 회수가 조과에 유리
- XG(엑스트라 하이기어)도 적합

### PE 라인
- **1호** — 표준. 광어/농어/우럭 워킹루어 전반에 가장 널리 쓰임. 비거리와 강도의 균형이 좋음
- **0.8호** — 비거리 우선, 얕은 포인트나 소형 어종 위주일 때
- **1.2호 이상** — 험한 지형, 밑걸림 많은 포인트, 강제 집행 필요할 때

### 쇼크리더
- 카본(플루오로카본) 3~4호, 1.5~2m 연결 권장
- FG노트 또는 유니노트로 접속

### 기타
- 수심 5m 이내: 지그헤드 1/4~1/2oz
- 수심 7~10m: 1/2oz 전후
- 웜 색상: 흐린 날/수온 낮을 때 → 어두운 계열, 맑고 따뜻할 때 → 밝은 계열(흰색/핑크)

## 광어 다운샷 (선상)

### 기본 개념
- 수직으로 채비를 내려 바닥을 긁는 방식 — 캐스팅 아님
- 베이트릴이 표준 (수심 파악, 조작 편의성). 스피닝릴도 불가능하진 않지만 일반적이지 않음
- 수심 카운터 내장 릴이면 바닥 파악에 유리 (예: 염월 프리미엄)

### 서해 기준 (안면도 등)
- 주요 출항지: 영목항 등 안면도 일대
- 수심: 10~20m 일반적
- 서해 조류가 강하므로 봉돌을 충분히 무겁게 준비

### 릴
- 베이트릴 권장 (150~200번급)
- 수심 카운터 있으면 더 유리

### PE 라인
- **1~1.5호** 표준
- 수심이 얕아 150m 스풀로도 충분

### 쇼크리더
- 카본 4~5호, 1m 전후
- 스냅도래로 연결해도 무방 (채비 교체 편리)

### 봉돌
- **20~40호 (75~150g)** — 서해 조류 강할 때 40호 이상
- 봉돌과 웜 간격: 25~30cm (너무 멀면 챔질 실패 증가)

### 웜
- 3~4인치 그럽 또는 섀드웜
- 색상: 붉은색, 오렌지, 흰색, 검은색 계열 / 반짝이 혼합 제품 유리
- 액션: 고패질 자제 — 조류에 하늘거리게 두는 게 입질 유리
- 어초 접근 시 밑걸림 주의 — 바닥 찍히면 4~5바퀴 감아 회피

## 동해 락피싱 (록피시 / 볼락 등)

### 기본 개념
- 동해 갯바위·방파제에서 볼락, 우럭, 열기 등 암초어종을 노리는 장르
- 연안 라이트게임 — 가벼운 채비와 섬세한 조작이 핵심

### 릴
- 스피닝릴 1000~2000번 (얕은 포인트 기준)
- 드랙력 3kg 전후면 충분
- 섈로우 스풀 권장 — PE 라인이 얇아 깊은 스풀 불필요

### PE 라인
- **0.3~0.6호** — 볼락/아징 등 초경량 장르
- **0.6호** — 범용 동해 락피싱 표준. 최근 대형 볼락 노릴 때도 0.6호 트렌드
- 100~150m면 충분

### 쇼크리더
- 카본 1~2호, 1~1.5m
- FG노트 권장

### 루어
- 지그헤드 0.5~8g + 소프트웜 (1.5~3인치)
- 메탈지그 5~20g (원거리 공략 시)
- 야간 집어등 효과 좋음

## SLJ (슈퍼라이트지깅)

### 기본 개념
- 라이트지깅보다 더 가벼운 메탈지그를 사용하는 선상 장르
- 볼락, 우럭, 전갱이, 방어, 부시리, 갈치 등 다양한 어종 대상
- 시즌 연중 가능. 가을이 피크 (가장 다양한 어종)

### 릴
- 스피닝릴 또는 베이트릴 모두 가능
- 스피닝: 2500~3000번 / 베이트: 150~200번급
- 수심 카운터 베이트릴이 편리하나 스피닝으로도 무방

### PE 라인
- **0.6~1호** 표준
- 수심 50~100m 공략 시 200m 이상 권장

### 쇼크리더
- 카본 2~4호, 1.5~2m

### 지그
- **10~60g** 메탈지그 (수심·조류에 따라 조절)
- 팔랑거리거나 진자운동하며 떨어지는 폴링형 지그 권장
- 수직 낙하·빠른 침강 지그는 비추천
- 액션: 바닥 찍고 3~4m 크게 띄웠다 가라앉히기 반복
- 어시스트훅 앞뒤 세팅 기본

## 선상 광어 캐스팅

### 기본 개념
- 선상에서 캐스팅 후 바닥을 긁어 광어를 노리는 방식
- 다운샷과 달리 캐스팅으로 넓은 면적 탐색
- 스피닝릴 또는 베이트릴 모두 사용

### 릴
- 스피닝릴 2500~3000번 또는 베이트릴 150번급

### PE 라인
- **0.8~1호** 표준

### 쇼크리더
- 나일론 또는 카본 16~20lb, 1~2m

### 루어
- 지그헤드 1/2~1oz + 3~4인치 섀드웜/그럽
- 메탈지그 20~40g, 싱킹미노우 15g, 바이브레이션 25~35g

## 서프 루어 (해변 캐스팅)

### 기본 개념
- 모래사장(서프)에서 멀리 캐스팅해 광어, 농어, 삼치 등을 노리는 장르
- 비거리가 생명 — 긴 로드와 가벼운 라인 필요

### 릴
- 스피닝릴 3000~5000번
- 대형 스풀로 비거리 확보

### PE 라인
- **0.8~1.5호** — 비거리 우선이므로 가능한 가늘게
- 서프 특성상 200m 이상 권장

### 쇼크리더
- 나일론 또는 카본 20~30lb, 2~3m (파도·모래 마찰 대비)

### 루어
- 메탈지그 20~80g (원거리 탐색)
- 싱킹미노우 15~25g
- 바이브레이션 20~40g

---

## 선상 문어

### 릴
- 베이트릴 150~200번급
- 드랙력 4.5kg 이상, 기어비 5.4:1 전후

### PE 라인
- **1.5~3호** — 문어 특성상 강도 중요

### 채비
- 문어용 에기 (고추장/수박/색동/금색/은색 컬러 준비)
- 봉돌 — 출조 당일 선사에서 확인 (수심·조류에 따라 상이)
- 바닥을 천천히 읽으며 탐색 — 문어는 돌·홈통에 숨어있음

## 선상 주꾸미·갑오징어

### 기본 개념
- 서해 얕은 수심(5~15m)에서 바닥을 탐색하는 장르
- 베이트릴이 표준 — 수직으로 채비를 내리고 바닥을 읽기 쉬움
- PE에 쇼크리더 없이 직결 사용이 일반적

### 릴
- 베이트릴 권장 — 기어비 6점대 이상
- 스피닝릴도 가능하나 비표준
- 수심이 얕아 수심 카운터 없어도 무방

### PE 라인
- **0.8~1호** 표준
- 수심 5~15m로 얕아 150m면 충분

### 쇼크리더
- 일반적으로 **불필요** — PE에 직결 사용
- 밑걸림 심한 포인트에서는 카본 2~3호 1m 연결하기도 함

### 봉돌
- 서해 기준 **5~15호** (조류 약하면 가볍게, 강하면 무겁게)
- 봉돌이 너무 무거우면 어신 파악 어려움 — 바닥 닿는 감 유지하면서 최대한 가볍게 쓰는 것이 정답
- 갑오징어 에기 6~9g 기준, 봉돌 3호(11~12g)가 기준점

### 채비
- 1단 채비 (에기 1개 + 봉돌): 기본, 어신 파악 쉬움
- 2단 채비 (에기 2개): 주꾸미·갑오징어 동시 공략 가능, 저항 큼
- 에기는 갑오징어용 6~9g 사용

### 지역별 특성

**안면도 (영목항) 기준**
- 주요 수심: 5~15m
- 서해 조류 영향 받음 — 봉돌은 조류에 맞게 현장 조정
- 주꾸미·갑오징어 동시 시즌 (9월~11월 피크)
- 야간 투광등에 주꾸미가 수면으로 올라오는 특성 있음

## 선상 심해 갑오징어

### 기본 개념
- 수심 60~100m 이상 심해 포인트 공략
- 일반 갑오징어와 달리 전동릴 또는 수심 카운터 필수
- 야간 출조가 일반적 (집어등 사용)

### 릴
- 소형 전동릴 또는 수심 카운터 베이트릴
- 수심 100m 대응 가능한 라인 용량 필요
- 수동릴 사용 시 60~70m 반복 감기로 체력 소모 큼 — 전동릴 권장

### PE 라인
- **0.8~1.25호** 표준
- **200m 이상 필수** (수심 + 여유분)

### 쇼크리더
- 카본 3~4호 1~1.5m
- 지형에 따라: 여밭(남해) → 4~5호 / 뻘 지형(제주) → 3~4호로 가늘게 OK

### 봉돌
- **30~50호** — 수심 깊어 무거운 봉돌 필요
- 선사에서 당일 봉돌 호수 지정해주는 경우 많음

### 채비
- 삼봉에기(스테) + 가지채비 구성
- 꽁치포 등 생미끼 병용 효과적
- 야광·발광 에기 준비

### 지역별 특성

**제주 한림 기준**
- 주요 수심: 60~70m (겨울 기준, 수온 낮을수록 깊어짐)
- 지형: 뻘 바닥 — 밑걸림 거의 없음 (서해 여밭과 다름)
- 입질이 예민 — 대끝을 살짝 털어 스테에 액션 후 쫀쫀한 느낌 오면 챔질
- 시즌: 12월~이듬해 5월 (겨울이 메인 시즌)
- 봉돌 바닥에서 스테를 약간 띄우거나 붙여 쓰는 두 방식 모두 유효

**남해(여수 등) 기준**
- 수심 80~100m 이상
- 여밭 지형 → 쇼크리더 굵게 (4~5호)

### PE 호수 용도 요약
| 호수 | 용도 |
|------|------|
| 0.3~0.4호 | 아징, 초경량 락피싱 |
| 0.6호 | 동해 락피싱, 볼락, 에깅 팁런 |
| 0.8호 | 에깅, 라이트 워킹루어, SLJ |

| 1.5~3호 | 선상 문어, 심해 갑오징어 |
| 2호 이상 | 부시리 지깅, 쇼어지깅 |

## 참돔 타이라바 (선상)

### 기본 개념
- 타이라바를 바닥까지 내린 후 느린 등속으로 감아올리는 장르
- 느린 등속 감기가 핵심 — 저기어(PG) 릴이 등속 유지에 유리
- 수심 카운터 내장 릴이면 포인트 수심 파악과 채비 관리에 유리
- 타이라바는 스냅도래 없이 쇼크리더에 직결이 기본 (스냅도래 사용 시 루어 움직임 저하, 긁힌 부위 파손 위험)

### 서해 공통 기준 (군산, 인천권)
- 군산 주요 수심: 30~40m (포인트에 따라 8~15m 얕은 곳도 있음)
- 인천권(영흥도, 덕적도 등) 수심: 30~60m로 군산보다 깊은 편, 조류도 강함
- 서해 특성: 조류 빠름, 여밭(암초) 많음 → 쇼크리더 굵게 사용
- 시즌: 5월 중순~11월 초순

### 릴
- 베이트릴 권장 — 수심 카운터 내장 모델이 이상적
- 저기어(PG, 5.8:1 전후) — 느린 등속 감기 유지에 유리
- 타이라바 전용 세트 2개를 맞출 경우 같은 기어비 릴 두 개가 오히려 일관성 있음
  (예: 염월 프리미엄 + 염월 CT 조합 — 스풀 스펙 동일, 라인만 다르게 세팅)

### PE 라인
- **1.2~1.5호** 표준 (서해 기준)
- 수심 깊은 제주·남해는 0.8~1호로 가늘게
- 200m 이상 감아두는 것이 경제적 (여밭 밑걸림으로 원줄 소모 많음)

### 쇼크리더
- **카본 5호, 2~3m** — 군산 여밭 기준 권장
- 카본이 나일론보다 마찰·긁힘에 강해 유리
- 출조 중 쇼크리더가 심하게 긁혔으면 과감히 잘라내고 재연결

### 타이라바 무게
- 수심 30~40m: **50~80g**
- 조류 강할 때: **90g 이상**
- 텅스텐 소재가 같은 무게에 부피 작아 조류 저항 적음 → 권장
- 인치꾸는 서해에서 효과 떨어짐 (제주·남해 장르)

### 색상
- 물색 흐릴 때 / 흐린 날: **핑크, 녹색**
- 맑고 화창할 때: **빨강, 주황**

### 액션
- 물 맑은 여밭: 바닥 찍고 빠르게 올렸다 내리는 속공 패턴
- 물색 흐리고 뻘밭: 멀리 날려 수중여 주변을 천천히 훑는 패턴
- 활성 낮을 때: 타이라바 바늘에 갯지렁이 추가 — 후각+시각 집어 효과

## 동해 선상 락피싱 (속초 등)

### 기본 개념
- 선상에서 스피닝릴 + 지그헤드 + 그럽웜으로 볼락, 우럭, 쥐노래미 등 암초어종 공략
- 연안 락피싱과 달리 수심이 있어 지그헤드 무게가 훨씬 무거움
- 채비를 바닥까지 내린 후 슬로우 리트리브 또는 바닥~중층 탐색

### 릴
- 스피닝릴 2500~3000번
- 하이기어(HG) 이상 권장 — 빠른 라인 회수, 채비 조작 편의성

### PE 라인
- **0.8~1호** 표준
- 150~200m면 충분

### 쇼크리더
- 카본 2~4호, 1~1.5m
- 라인 호수에 따라: 0.8호 → 카본 2~3호 / 1호 → 카본 3~4호

### 지그헤드 무게 (경험 기반)
- **3/4oz (약 21g)** — 조류 약하거나 수심 얕을 때
- **1oz (약 28g)** — 기본 표준
- **1-1/2oz (약 42g)** — 조류 강하거나 수심 깊을 때
- 연안 락피싱(3~10g)과 무게가 완전히 다름 — 혼동 주의

### 웜
- 2~3인치 그럽웜
- 색상: 어두운 날 → 어두운 계열, 맑은 날 → 흰색·붉은색

## 에깅 팁런 (선상)

### 기본 개념
- 선상에서 수심 20~30m 이상을 수직으로 공략하는 무늬오징어 낚시
- 일반 에깅과 달리 캐스팅 없이 수직으로 에기를 내리고 조류에 흘리는 방식
- 입질이 로드 팁의 미세한 움직임으로 전달 — 감도가 핵심
- 야간 출조가 일반적 (집어등으로 오징어 유인)

### 릴
- 스피닝릴 2500~3000번
- 에깅 전용 더블핸들 모델 권장 (세피아BB 등)
- 드랙 성능 중요 — 무늬오징어 특유의 분사 대응

### PE 라인
- **0.4호** — 팁런 정석. 가는 라인이 수류 저항 최소화 → 입질 감도 향상
- **0.6호** — 조류 강하거나 수심 깊을 때 타협점
- **0.8호** — 팁런보다 굵지만 강한 조류 대응용
- 라인이 굵으면 물 저항 증가 → 에기가 제대로 가라앉지 않고 입질 감도 저하
- 100~150m면 충분 (수심 30m + 여유분)

### 쇼크리더
- 카본 1.5~2호, 1.5m 전후
- 가는 라인에 맞게 리더도 최대한 가늘게
- 무늬오징어는 투명도에 민감 — 굵은 리더 비추천

### 팁런 에기
- 일반 에기보다 10g 이상 무거운 전용 에기 사용
- 3.5호 기준 30g 전후 — 수심 30m 이상에서 수직 침강 가능
- 수심·조류에 따라 무게 조절 필수
- 야간/수심 깊을 때: 빨강·오렌지 등 채도 높은 컬러, 야광 계열
- 물색 맑을 때: 금색·은색 또는 내추럴 컬러

### 액션
- 바닥 찍고 에기를 짧게 샤크럿 후 수평으로 끌어주기 반복
- 입질은 팁이 휘거나 반대로 펴지거나, 라인 텐션이 사라지는 형태
- 살짝 챔질로 확인 — 수심 깊을수록 챔질 강도를 높여야 바늘 관통
