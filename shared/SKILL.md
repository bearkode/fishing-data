# 낚시 출조 세팅 스킬

사용자가 출조 장르와 지역을 언급하면, 보유 장비 중 최적의 릴+라인+쇼크리더+밑줄 조합을 추천한다.

## 참조 파일

| 파일 | 용도 |
|------|------|
| `reels.json` | 개인 보유 릴 목록 (specId로 reel-specs.json 참조, 개인 메모) |
| `reel-specs.json` | 릴 제조사 공식 스펙 (기어비, 권사량, 스풀 스펙, 핸들 권상량 등) |
| `lines.json` | 메인라인 재고 (호수, 잔량, 사용횟수, 이어붙임 여부와 길이) |
| `backing-lines.json` | 밑줄 전용 라인 재고 (폐카본 등 소모품) |
| `line-specs.json` | 라인 제품별 스펙 (직경, 강도, 합사수, 코팅, 장르 적합성) |
| `fishing-knowledge.md` | 장르별 세팅 지식 (PE 호수, 쇼크리더, 채비, 지역별 특성) |
| `backing-records.md` | 밑줄 성공 사례 및 실측 스풀 용량 데이터 |

---

## 추천 흐름 요약

1단계 장르 파악 → 2단계 세트 구성 계획 → 3단계 릴 배정 → 4단계 라인 배정 → 5단계 밑줄 계산 → 6단계 쇼크리더 → 7단계 추가 채비 → 8단계 주의사항 → 9단계 지식 업데이트

---

## 1단계 — 장르 및 지역 파악

- `fishing-knowledge.md`에서 해당 장르 섹션 확인
- 지역명이 있으면 지역별 특성 반영 (군산 여밭 → 쇼크리더 5호, 안면도 → 봉돌 호수 등)
- 장르 지식이 없으면 웹 검색 후 추천, 9단계에서 knowledge 추가 제안
- **유사 장르명 주의**: "동해 락피싱"(연안)과 "동해 선상 락피싱"은 완전히 다른 세팅 (지그헤드 무게가 3~10g vs 21~42g). 사용자가 어느 쪽인지 모호하면 확인 질문

---

## 2단계 — 세트 구성 계획

세트 수는 사용자가 요청한 수에 맞춤 (미언급 시 기본 2세트).

**세트별 역할 정의 (다중 세트 시):**

| 세트 | 역할 | 우선 기준 |
|------|------|-----------|
| 메인 | 가장 적합한 세팅 | 장르 표준에 가장 가까운 릴 + 신선한 라인 + 장르 전용 라인 우선 |
| 서브 | 백업 또는 다른 호수 | 메인과 다른 호수 또는 다른 강도로 다양성 확보 |
| 게스트 | 조작 편의 우선 | 단순한 릴(스피닝 우선), 사용횟수 많은 라인 OK, 비싼 라인 회피 |

---

## 3단계 — 릴 배정

**장르별 릴 매칭 (reels.json 필터):**

| 장르 | 우선 릴 타입 | 추가 조건 |
|------|--------------|-----------|
| 광어 캐스팅 / 연안 / 워킹루어 | 스피닝 2500~3000번 | HG/XG 우선 |
| 에깅 / 팁런 | 스피닝 2500~3000번 | 더블핸들 우선, 8합 라인 적합 |
| 선상 락피싱 | 스피닝 2500~3000번 | HG 이상 |
| 타이라바 | 베이트 150번급 | PG(저기어), 수심 카운터 강력 권장 |
| 광어 다운샷 (선상) | 베이트 150~200번급 | 수심 카운터 권장 |
| SLJ | 스피닝 2500~3000 또는 베이트 150~200 | 양쪽 가능 |
| 선상 문어 / 심해 갑오징어 | 베이트 150~200번급 | 드랙력 4.5kg 이상 |
| 주꾸미·갑오징어 | 베이트 | 6점대 이상 기어비 |
| 서프 루어 | 스피닝 3000~5000번 | 대형 스풀 |

**다중 세트 배정 규칙:**
- 한 릴은 한 세트에만 배정
- 메인 → 서브 → 게스트 순으로 우선순위 높은 릴부터 배정
- 같은 스풀 스펙(예: 염월 프리미엄 + 염월 CT)은 메인-서브로 짝지을 수 있음
- 게스트 세트는 스피닝릴 우선 (베이트릴 조작 부담 회피)
- 릴이 부족하면: 권사량 미확인 릴도 추정으로 활용 가능 (사용자에게 추정값임을 명시)

---

## 4단계 — 라인 배정

**기본 원칙: 보유 재고 우선. 신규 구매는 보유 라인으로 도저히 대응 불가할 때만 최후 수단으로 제안.**

### 4.1 후보 라인 필터링

`lines.json`에서 아래 조건으로 후보 좁히기:
1. **장르 호수 범위 충족** — `fishing-knowledge.md`의 권장 호수
2. **장르 적합성 충족** — `line-specs.json`의 `preferredGenres` / `avoidGenres` 확인
3. **잔량 충족** — 라인 길이가 장르별 필요 길이 이상
4. **다중 세트 시 중복 회피** — 같은 라인을 두 세트에 동시 배정 금지

### 4.2 장르 적합성 규칙 (line-specs.json 참조)

| 라인 종류 | 처리 |
|-----------|------|
| 에깅 전용 (세피아 8+ 등) | 에깅/팁런 외 장르 **배제** — 비싼 전용 라인 보존 |
| 루어 전용 (핏불 8, PEX8 루어에디션 등) | 루어 낚시 장르 우선 배정 |
| 범용 (그랜드맥스 PEX8 등) | 어느 장르에나 사용 가능 |
| 내마모 특화 (듀라센서 Si2 등) | 여밭/험한 지형 장르 우선 |

### 4.3 동률 후보 시 우선순위 (line-specs.json 속성 반영)

| 장르 특성 | 우선 속성 |
|-----------|-----------|
| 감도 중요 (팁런/에깅) | 합사수 많은 라인 (8합 이상) |
| 비거리 중요 (서프/캐스팅) | 동호수 중 직경 가는 라인 (PEX8 루어에디션 등) |
| 강도 중요 (대물/여밭/문어) | lb/kg 높은 라인 |
| 내마모성 중요 (여밭/락피싱) | 코팅 라인 (Si2, Heat Sink) |
| 수심 파악 (선상 전반) | 마킹 있는 라인 |
| 기타 | 사용횟수 적은 라인 (신선도) |

### 4.4 장르별 최소 강도 (lb)

| 장르 | 최소 |
|------|------|
| 팁런 / 에깅 | 10lb |
| 광어 캐스팅 / 락피싱 | 15lb |
| 타이라바 / 다운샷 | 20lb |
| 문어 / 심해 갑오징어 | 30lb |

강도 데이터 없음(`lb: null`)이면 호수 기준으로 판단하고 데이터 없음을 명시.

### 4.5 이어붙인 라인 (spliced) 처리

**"최선의 세팅", "최적의 조합" 요청 시 배제 기준:**

| 조건 | 배제 기준 |
|------|-----------|
| 긴쪽 길이 (`max(spliceLengths)`) | 200m 미만 → 배제 |
| 사용횟수 (`useCount`) | 5회 이상 → 배제 |

배제된 라인이 있으면 이유 명시. 배제 후 후보가 없으면 신규 구매 제안.

**이어붙인 라인 사용 시 감기 방법 (필수 안내):**
- **짧은 쪽(`min(spliceLengths)`)을 먼저 스풀 안쪽으로** 감는다
- 이음매가 스풀 깊숙이 묻혀 실사용 구간에 나오지 않음
- 예) l7 (268+51): 51m 먼저 → 이음매 → 268m 바깥쪽

### 4.6 라인 절단 최소화

- **스풀 전체 사용 우선**: 권장 길이보다 라인이 길어도 스풀 용량이 허용하면 전체 감기
- **"XXm만 감으세요" 금지**: 스풀 전체 감기 또는 다른 라인 선택으로 안내
- 절단이 불가피하면 절단 사실 명시 + 잔량 처리 방법 안내

### 4.7 라인 길이 기준

- 연안 캐스팅: 150~200m
- 선상 (수심 30~50m): 150~200m
- 선상 (수심 50m 이상): 200m 이상
- 타이라바/여밭: 200m 이상
- 팁런: 100~150m

## 5단계 — 밑줄(Backing) 계산

### 5.1 밑줄 필요 여부 판단

- 메인라인이 스풀 용량보다 부족 → 밑줄로 부족분 채우기
- 메인라인이 스풀 용량보다 많이 짧아 충전율 80% 미만 예상 → 밑줄 권장
- 목표 충전율: **90% 이상**
- 충전율 90% 이상이면 밑줄 불필요

### 5.2 스풀 용량 추정

우선순위:
1. `backing-records.md`의 실측 데이터
2. `reels.json`의 공식 권사량 + `line-specs.json` 직경 환산
3. 권사량 미확인 릴: 유사 사이즈 릴의 권사량으로 추정 (추정값임을 명시)

**호수 환산 공식:**
```
환산 길이 = 스풀 기준 용량 × (기준 직경² / 메인라인 직경²)
```

직경 데이터 없으면 호수 기준 단면적 비율로 근사.

**그랜드맥스 PEX8 사용 시 주의:** 실제 직경이 표기보다 굵음 → 공식 스펙보다 적게 감기므로 여유 있게 계산.

### 5.3 밑줄 라인 선택

| 우선순위 | 라인 |
|----------|------|
| 1순위 | **`backing-lines.json`의 밑줄 전용 라인** — 잔량 충분하면 항상 첫 후보 |
| 2순위 | `lines.json`에서 메인라인보다 굵은 호수의 라인 |
| 3순위 | `lines.json`에서 사용횟수 많은 라인 (소모품으로 활용) |

### 5.4 밑줄 감기 순서 (항상 안내)

1. 밑줄을 **먼저** 스풀에 감기
2. 밑줄 끝과 메인라인 연결 (FG노트 또는 유니노트)
3. 메인라인 감기 (이어붙임 라인은 짧은 쪽을 밑줄 쪽으로)

**핸들 회전수 안내:** `windingPerRotation_cm` 기준으로 계산해서 함께 표시.

### 5.5 출력 형식

```
🪢 **밑줄 권장 (충전율 XX%)**
- 밑줄: 폐카본 (l16) 약 XXm
- 감기 순서: ① 폐카본 XXm → ② FG노트로 연결 → ③ 메인라인 XXm
- 핸들 회전수: 약 XX회전 (릴 권상량 XXcm 기준)
- 결과 충전율: 약 XX%
```

## 6단계 — 쇼크리더 추천

**라인 호수 기반 기본 매칭:**

| PE 호수 | 카본 쇼크리더 | 길이 |
|---------|--------------|------|
| 0.4호 | 1.5~2호 | 1.5m |
| 0.6호 | 2호 | 1.5m |
| 0.8호 | 2~3호 | 1~1.5m |
| 1호 | 3~4호 | 1~2m |
| 1.2호 | 4~5호 | 2~3m |
| 1.5호 | 5호 | 2~3m |

**장르별 예외 (우선 적용):**
- 타이라바 (서해 여밭): 카본 5호 고정, 2~3m
- 광어 다운샷 (선상): 카본 4~5호, 1m 전후
- 서프루어: 나일론 또는 카본 20~30lb, 2~3m
- 주꾸미/갑오징어: 쇼크리더 불필요 (PE 직결)
- 문어: 직결 또는 카본 5호 1m

## 7단계 — 추가 채비 정보

장르별로 함께 제공:

| 장르 | 추가 정보 |
|------|----------|
| 타이라바 | 무게(수심별 50~100g), 색상(날씨/물색별), 직결 사용 |
| 락피싱(선상) | 지그헤드 무게 oz 단위(3/4~1-1/2oz), 웜 2~3인치 |
| 광어 다운샷 | 봉돌 호수(서해 20~40호), 웜 3~4인치 |
| 팁런 | 에기 무게(30g 전후), 색상(야간/주간) |
| SLJ | 지그 무게 g 단위(10~60g), 폴링형 지그 |
| 주꾸미/갑오징어 | 봉돌 호수(서해 5~15호), 에기 6~9g |
| 심해 갑오징어 | 봉돌 30~50호, 삼봉에기 + 가지채비 |

## 8단계 — 주의사항 체크

세팅 추천에 다음 항목 점검 후 ⚠️ 섹션에 포함:

- 폐카본 누적 사용량 표시 (다중 세트 시 합계)
- 이어붙인 라인의 감기 방향 안내
- 사용횟수 많음(5회 이상) → 교체 권장 메시지
- 권사량 추정값 사용 시 → 실측 후 backing-records.md 업데이트 필요 메모
- 스풀 용량 빠듯한 경우 → 절단 또는 호수 변경 검토 안내

---

## 9단계 — 지식 자동 업데이트

세팅 후 아래 조건 중 하나라도 해당하면 knowledge를 업데이트하고 교체 업로드 요청:

**업데이트 트리거:**
- 웹 검색으로 새로운 장르·지역 세팅 정보 발견 → 섹션 신규/보완
- 사용자가 추천을 수정하거나 다른 정보 제공 → 반영
- 지역별 특성 파악 → 기존 섹션에 지역 서브섹션 추가
- 사용자 경험 기반 데이터 (지그헤드 무게, 봉돌 호수 등) → 경험값으로 기록

**업데이트 대상:**
- `fishing-knowledge.md` — 장르/지역 세팅 지식
- `backing-records.md` — 밑줄 성공 사례, 실측 스풀 용량
- `line-specs.json` — 새로 알게 된 라인 스펙
- `reels.json` — 권사량 실측 후 업데이트

**원칙:**
- 기존 내용 덮어쓰지 않고 보완
- 경험 기반 데이터는 "경험 기반" / "실측" 명시
- 검색 데이터와 경험 데이터 충돌 시 경험 우선, 두 값 모두 기록
- 변경 내용 간략히 알리고 교체 업로드 요청

## 엣지 케이스

- **장르 지식 없음**: 웹 검색 후 답변, knowledge 추가 여부 확인
- **적합한 릴 없음**: 가장 근접한 릴 + 부족 이유 설명
- **라인 재고 부족**: 보유 라인으로 대안 먼저 (밑줄 활용, 인접 호수, 짧은 라인 활용 등). 정말 불가능하면 "보유 라인 중 대안이 없어 신규 구매가 필요합니다" 명시
- **세트 수 미언급**: 기본 2세트
- **지역 정보 있음**: fishing-knowledge.md의 지역별 특성 반영
- **권사량 미확인 릴**: 유사 사이즈 릴로 추정, 실측 후 업데이트 필요 메모
- **다중 세트 라인 충돌**: 호수 다른 라인으로 분산, 세트별 역할에 맞춰 우선순위 차등
